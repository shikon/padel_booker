GitHub Pages Hosting & Live Court API Setup

How this app fetches Veldhoven & Eindhoven indoor courts on a static GitHub Pages site

Why a GitHub Action or CORS Proxy is used on GitHub Pages: Static sites hosted on username.github.io run purely in the browser. While Playtomic, Bookaball, and Peakz (FOYS) all have JSON APIs, browser CORS policies block direct cross-origin requests from unknown domains. You have 3 zero-cost ways to use this app:
  1. Instant Smart Mode (Active out of the box): Realistic availability modeling + 1-click deep links + Stateless URL Match Polling (?match=...) for your WhatsApp group.
  2. GitHub Actions Auto-Scraper (Recommended for 100% live courts): Drop the included .github/workflows/update-courts.yml and fetch_courts.py into your repo. GitHub's servers bypass CORS, fetch live courts every 30 mins, and commit ./availability.json which this page automatically loads!
  3. Cloudflare Worker CORS Proxy: Paste a free Cloudflare Worker URL in Tab 3 to query Playtomic directly from the browser.

Save this file as .github/workflows/update-courts.yml in your GitHub Pages repository alongside fetch_courts.py: 

name: Update Padel Availability

on:
  workflow_dispatch:
  schedule:
    - cron: '*/30 * * * *'

permissions:
  contents: write

jobs:
  fetch-courts:
    runs-on: ubuntu-24.04
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: |
          pip install requests playwright
          playwright install --with-deps chromium

      - name: Fetch live VHV & EHV indoor courts
        run: python fetch_courts.py

      - name: Commit updated availability.json
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add availability.json
          git diff --quiet && git diff --staged --quiet || git commit -m "chore: update indoor padel slots"
          git push
